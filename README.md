# Casino Thing

A Java blackjack and poker game.

## Play on macOS

1. Download `CasinoThing-macOS.zip` from the Releases section.
2. Unzip it.
3. Keep `Run-Game.command` beside `Game.app`.
4. Double-click `Run-Game.command` to start the game in Terminal.

The launcher opens the game in Terminal. If macOS blocks it, right-click
`Run-Game.command`, choose **Open**, then confirm.
